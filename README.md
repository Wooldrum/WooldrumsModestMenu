# Wooldrum's Modest Menu

BepInEx mod for **Approximately Up Demo** (host installs it).

## Install

PowerShell, from this folder:

```powershell
.\install.ps1
```

Wrong game folder? Use `-GameDir` with the path that contains `ApproximatelyUp.exe`.

## Open

Start the game, get in-game, press **F8** to open or close the menu.
You must load onto a planet first, then invite people. You will experience bugs if you invite people first.
